# auroraOSP.github.io

Website for **AuroraOSP** — a private-source Android 17 distribution built on AOSP
and LineageOS 24.0.

The ROM source is not public. Nothing on this site should imply otherwise: no
repository links, no "open source", no Apache 2.0 licence claim over Aurora's own
code. Upstream components (AOSP, LineageOS, the Linux kernel) keep their own
licences and are described as such on the About page.
