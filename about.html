About

A ROM built for people who fiddle.

AuroraOSP started from a simple frustration: Pixel software is genuinely good, and almost none of it is adjustable. Meanwhile the custom ROM scene had all the switches and none of the polish.

So Aurora does both. It builds on AOSP through LineageOS 24.0, brings across Google's own Settings and System UI along with the Pixel framework overlays and partner modules that make the Pixel feel like a Pixel — and then adds the settings surface Google never shipped, in Aurora's own Liquid Glass language, translated into 13 languages.

Open by default

Device trees, vendor configuration and Aurora's own apps are public on GitHub and GitLab under Apache 2.0. If a feature is in a build, the code that made it is readable.

No telemetry

Aurora collects nothing. There is no analytics SDK, no crash uploader phoning home, and no account required. VANILLA builds contain no Google services at all.

Maintained, not abandoned

Aurora tracks upstream AOSP security patches through LineageOS, and rebases onto new Android releases rather than freezing on an old one.

How it's built

The stack

Four layers, each one auditable.

  • Layer 1 Android Open Source Project

    Android 17 (API 37) as the base platform, with monthly upstream security bulletins.

  • Layer 2 LineageOS 24.0

    Device support, hardware abstraction, the Lineage SDK, and the maintained device and kernel trees that make broad hardware support possible.

  • Layer 3 Pixel software stack

    Google's Settings and System UI builds, Pixel framework overlays, partner modules and the vendor interfaces they depend on — the parts that make Now Playing, adaptive charging and the Pixel launcher behave correctly.

  • Layer 4 Aurora Hub

    Aurora's own customisation surface, and the System UI, launcher, theme picker, files and music work behind it: Liquid Glass, the Now Bar, resizable Quick Settings, lock screen lyrics and depth, eight power menus, Play Integrity Fix and TrickyStore.
